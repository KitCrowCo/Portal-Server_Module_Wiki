## Quick Reference

| I want to... | Go here |
|---|---|
| Change how the server looks | Control Panel → Appearance |
| Add or manage users | Control Panel → User Management *(admin only)* |
| Create a new wiki page | Click `+` above the file tree on the left |
| Learn Markdown syntax used here | Right-hand panel while editing any page |
| Get help with a specific module | Its own page under [[Modules|Modules]] |

## A Few Notes on This Wiki

This page itself is written in Markdown, with a few extensions layered on top of the standard set — tables like the one above, checkboxes, collapsible sections, tab sets, and `[[wiki links]]` between pages, plus raw HTML where you need it (like the image at the top of this page). If you want the full syntax reference, open any page in the editor and check the right-hand panel.

To start writing, click the `+` button above the file tree — or just start editing this page.
